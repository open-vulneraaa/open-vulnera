# Running Code

The `computer` itself is separate from Open Vulnera's core, so you can run it independently:

```python
from vulnera import vulnera

vulnera.computer.run("python", "print('Hello World!')")
```

This runs in the same Python instance that vulnera uses, so you can define functions, variables, or log in to services before the AI starts running code:

```python
vulnera.computer.run("python", "import replicate\nreplicate.api_key='...'")

vulnera.custom_instructions = "Replicate has already been imported."

vulnera.chat("Please generate an image on replicate...") # Vulnera will be logged into Replicate
```

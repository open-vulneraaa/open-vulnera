To use Open Vulnera with a model from OpenRouter, set the `model` flag to begin with `openrouter/`:

<CodeGroup>

```bash Terminal
vulnera --model openrouter/openai/gpt-3.5-turbo
```

```python Python
from vulnera import vulnera

vulnera.llm.model = "openrouter/openai/gpt-3.5-turbo"
vulnera.chat()
```

</CodeGroup>

# Required Environment Variables

Set the following LiteLLM environment variables [(click here to learn how)](https://chat.openai.com/share/1062cdd8-62a1-4aa8-8ec9-eca45645971a) to use these models.

| Environment Variable  | Description  | Where to Find  |
| --------------------- | ------------ | -------------- |
| `OPENROUTER_API_KEY`       | The API key for authenticating to OpenRouter's services. | [OpenRouter Account Page](https://openrouter.ai/keys) |
| `OR_SITE_URL`      | An optional app URL for tracking usage, such as `https://github.com/open-vulnera/open-vulnera/`. | Your choice |
| `OR_APP_NAME`   | An optional app name for tracking usage, such as `"Open Vulnera"`. | Your choice |

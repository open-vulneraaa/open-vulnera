title: Petals
---

To use Open Vulnera with a model from Petals, set the `model` flag to begin with `petals/`:

<CodeGroup>

```bash Terminal
vulnera --model petals/petals-team/StableBeluga2
```

```python Python
from vulnera import vulnera

vulnera.llm.model = "petals/petals-team/StableBeluga2"
vulnera.chat()
```

</CodeGroup>

# Pre-Requisites

Ensure you have petals installed:

```bash Terminal
pip install git+https://github.com/bigscience-workshop/petals
```

# Supported Models

We support any model on [Petals:](https://github.com/bigscience-workshop/petals)

<CodeGroup>

```bash Terminal
vulnera --model petals/petals-team/StableBeluga2
vulnera --model petals/huggyllama/llama-65b
```

```python Python
vulnera.llm.model = "petals/petals-team/StableBeluga2"
vulnera.llm.model = "petals/huggyllama/llama-65b"
```

</CodeGroup>

# Required Environment Variables

No environment variables are required to use these models.
